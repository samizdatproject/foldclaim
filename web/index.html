FoldClaim

FoldClaim is a pull-based reward pool for CashTokens on Bitcoin Cash, written in SolidCash: the operator publishes one Merkle root per epoch instead of pushing one output per user. Each recipient claims whenever they like, pays only their own fee, and the contract tracks what was already paid, so nobody needs a receipt NFT.

Test token on mainnet, not real FLDCH. The contracts and the 144-block audit window are real and live on BCH mainnet; the reward token is a worthless test token.

      How it works

      • Cumulative leaves. Each leaf commits to an address and the total it has earned so far, never a per-epoch amount, so a claim pays the difference, skipping epochs costs nothing and nothing expires.
      • 144-block audit window. A proposed root waits about one day (a relative timelock on the registry) before anyone can activate it, so watchers can rebuild it from the public Folding@home files.
      • Receipts as a verified mapping. The pool keeps claimed[address] in its own token category; a repeat claim is refused on-chain, and users hold no receipt NFT.
      • Payout bound to the leaf address. The address is part of the leaf hash and the contract pays only that locking bytecode, so nobody can redirect a claim.
      • Anyone can relay. The user, a relayer or the operator can submit a claim and pay its fee; activation and sync are permissionless too.

      Built with Claude Code. Reads public Electrum servers directly from your browser; no trackers, no keys. The only other server it can contact is the optional demo relayer, and only when you press its Claim button.
